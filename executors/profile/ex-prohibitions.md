## Absolute prohibitions

Violating any of these destroys other agents' work or the principal's.

- **NEVER run any git command.** Not `checkout`, not `restore`, not `stash`, not `reset`,
  not `revert`, not `clean`, not `add`, not `commit`. **Not even to undo something you did
  wrong.** If you made a mistake, fix it by editing the file forward.
  Reason: you work in parallel with other agents on the same repository. A `git checkout`
  that looks like "cleaning up your error" silently wipes hours of someone else's work, and
  nobody finds out until much later.

- **NEVER regenerate generated artifacts.** API clients (e.g. an API client generated by
  `pnpm run api`, `openapi-generator`, or equivalent), schema types, codegen output,
  migrations. Regenerating them while others are working leaves the rest of the team
  compiling against a contract different from the one the principal believes is in place.

- **NEVER install or uninstall dependencies**, and never edit `package.json`, lockfiles,
  `pnpm-workspace.yaml`, or package manager configuration. If you believe a dependency is
  needed, **stop and report it**; do not install it.

- **NEVER start servers or run builds.** Nothing like `dev`, `start`, `start:dev`, `build`,
  `serve`. Assume the project is already running.

- **NEVER run database migrations** or write into any database.

- **NEVER create Markdown files** (README, notes, summaries) unless explicitly requested.

- **NEVER spawn subagents.** You are terminal. Do all the work with your own tools.

- **NEVER use `// prettier-ignore`** or `{/* prettier-ignore */}` or any variant. Not for
  long imports, not to force something onto one line. It breaks the project's formatting.
  If a line is too long, split it or extract a helper. If you find one in the code you
  touch, remove it.

- **Sole exception:** generated code (e.g. `src/generated-client/` or equivalent). It is
  emitted by a generator, ships with its own `prettier-ignore` markers, and is NOT touched
  by hand: the folder is regenerated whole. Never edit, format, or clean a file inside it.

- **Touch ONLY the files in your scope.** Other agents are editing other folders of the
  same package right now. If you need a change outside your scope, **report it instead of
  doing it**.
