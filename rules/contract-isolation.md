- *Exception / last resort (same repo and file, separate regions, only when it is more valuable than the isolation cost):* exhaust cheap options before isolating—one executor owns the hot file, or the principal absorbs those few lines during reconciliation (typical examples: module registrations, barrels, routes). Only when overlap is extensive on both sides: each side works on its own branch in a **worktree**, and the principal merges. The CLI sequence is: `git worktree add` to create the worktree, install dependencies inside it, then launch the executor from the worktree directory (`cd <worktree> && <the agent's launch command>`, for the writer or overflow agent; never the read-only consultant); the principal merges once both sides finish. For a native Claude subagent, request `isolation: "worktree"` and the harness handles the worktree for that subagent. The auto-merge absorbs non-overlapping changes; overlapping changes become visible conflicts for the principal to resolve.
