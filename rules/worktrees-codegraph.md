**Worktrees and CodeGraph:** right after `podium worktree create`, if the main checkout is indexed, run `codegraph init <worktree>` (it ignores the linked dependency folders; in background if large) and wait for it; no executor works there until the index exists, and every brief names the worktree as `projectPath`. The CodeGraph gate never asks the user about a git worktree: it blocks it until the index exists, unless the user declined indexing for the main checkout, which the worktree inherits. Worktree indexes are queried only through their explicit `projectPath`, never picked up as extra sub-projects of a parent folder.
