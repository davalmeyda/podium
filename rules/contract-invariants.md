**Invariants:** the principal ALWAYS does the merge, never agents; use a worktree only inside a git repo, never in a non-repo parent folder that holds several repos. Regenerated boundaries (for example, in repos that regenerate a client from the backend, such as an OpenAPI client) are regenerated by the principal, never edited or merged by hand. After parallel work, the principal reviews the actual integration (formats, errors, edge cases, backend/frontend consistency) and adjusts it; the goal is to reach reconciliation with 80–90% done.
